# 全体更新コマンド

ドキュメントとGitHub Projectsの両方を更新し、プロジェクト全体を最新状態にします。

## タスク

以下の2つのタスクを順番に実行してください：

### 1. ドキュメント更新

1. 現在のコードベースを確認し、以下のドキュメントを最新の状態に更新：
   - CLAUDE.md（開発ガイドライン）
   - README.md（プロジェクト説明）

2. 更新時の観点：
   - 開発コマンドが現在の実装と一致しているか
   - アーキテクチャ説明が最新か
   - 依存関係や環境要件が正確か
   - MCPサーバの設定・使用方法が正しいか

### 2. GitHub Projects更新

1. 現在のプロジェクト状況を確認：
   ```bash
   gh project item-list 3 --owner uzusio
   ```

2. 以下を確認・更新：
   - 完了済みタスクのステータス更新
   - 新しく必要になったタスクの追加
   - 不要になったタスクのクローズ
   - 優先度の見直し

### 3. 最終報告

両方の更新内容をまとめて報告してください。
