# コミット＆プッシュ＆Issue更新・クローズ

変更をコミットしてリモートにプッシュし、関連するIssueを更新してクローズする。

## 手順

### 1. ブランチとコミット情報の確認

1. `git branch --show-current` で現在のブランチを確認
2. ブランチの安全性チェック（下記参照）
3. `git status` で変更を確認
4. `git diff --stat` で差分の統計を確認
5. `git log --oneline -3` で直近のコミットメッセージのスタイルを確認

### 2. コミット実行

適切なコミットメッセージを作成してコミット

### 3. プッシュ実行

`git push` でリモートにプッシュ（新規ブランチは `-u origin <branch>` を使用）

### 4. Issueクローズの判定と実行

**重要**: プッシュ後は対象Issueを確認してクローズする

#### 4.1 対象Issue特定

以下の方法でIssue番号を特定：
1. **ブランチ名から**: `feature/multilingual-support` → 関連Issue
2. **コミットメッセージから**: メッセージに言及されているIssue番号
3. **ユーザーからの指示**: 明示的に指定されたIssue番号

#### 4.2 クローズ判定

以下の条件を**すべて満たす場合のみ**クローズする：
- ✅ Issue要件が完全に実装されている
- ✅ 動作確認が完了している
- ✅ ドキュメント・Skillが更新されている（必要な場合）

#### 4.3 Issueクローズ実行

```bash
gh issue close <issue-number> --comment "✅ 実装完了

## 実装内容
<変更内容の詳細>

## 動作確認
<確認結果のサマリー>

関連コミット: <commit-hash>"
```

### 5. Issueへのコメント追加（進捗報告のみの場合）

実装が完了していない場合や、部分的な進捗の場合：

```bash
gh issue comment <issue-number> --body "🔧 作業進捗

- <変更内容>

関連コミット: <commit-hash>"
```

### 6. Issue整理のガイドライン

- **完了判定**: 機能実装が完了し、動作確認も通過している場合は必ずクローズ
- **進捗報告**: 部分的な実装や調査結果をコミットした場合はコメントのみ
- **複数Issue**: 1つのコミットで複数のIssueに影響する場合、すべてに言及
- **クローズ優先**: 要件が満たされている場合は、必ずIssueをクローズする

## ブランチ安全性チェック

| ブランチ | コミット | プッシュ | 対応 |
|---------|---------|---------|------|
| `master` | ❌ 禁止 | ❌ 禁止 | PRを使用してください |
| `feature/*` | ✅ OK | ✅ OK | Issue対応時 |

## コミットメッセージ規約

**重要**: このプロジェクトでは日本語でコミットメッセージを書く（type接頭辞なし）

### 基本フォーマット

```
<日本語での説明>

<詳細説明（任意）>

```

### 例

```bash
# 良い例
マルチリンガル対応: VADベースのフレーズ単位言語検出を実装

# 悪い例（英語）
feat: Implement multilingual transcription with VAD segmentation

# 悪い例（type接頭辞付き）
feat: マルチリンガル対応を実装
```

## HEREDOCを使ったコミット例

複数行のコミットメッセージは必ずHEREDOCを使用：

```bash
git commit -m "$(cat <<'EOF'
マルチリンガル対応: VADベースのフレーズ単位言語検出を実装

- vad_segmenter.py: Silero VADによるフレーズ分割
- multilingual_transcriber.py: セグメント単位のWhisper推論
- 言語ホワイトリスト機能
- CLI/MCPサーバへの統合

EOF
)"
```

## 注意事項

- **日本語優先**: コミットメッセージは日本語で書く
- **type接頭辞なし**: このプロジェクトではtype接頭辞を使わない
- **HEREDOCの引用符**: `<<'EOF'` のようにシングルクォートで囲むことで変数展開を防ぐ
- **フッター必須**: 全てのコミットにClaudeフッターを追加
